# 会议记录员(meeting-recorder)

Granola 式会议记录插件:**会中**录音 + 随手记要点,分段实时转写;**会后** AI 把「你的要点 × 完整转写」融合成结构化纪要与行动项;**行动项跨会议再浮现**,勾选直接回写原笔记。

> 本仓是 [Forsion](https://github.com/Changan-Su/Forsion)(AI 原生笔记 + 内置 Tangu Agent 的本地优先桌面工作台)的社区插件,捆绑包(bundle)形态:UI 视图 + 随包「会议书记官」Agent + 随包 Space。转写走 Forsion 自带语音链路,零额外配置、零第三方 ASR。

## 安装

```bash
git clone https://github.com/Changan-Su/forsion-plugin-meeting.git
cd forsion-plugin-meeting
sh install.sh prod    # 安装到 ~/.forsion;开发家用 sh install.sh(默认 dev → ~/.forsion-dev)
```

重启 Forsion 桌面端后生效(引擎重启时自动播种「会议书记官」Agent):命令面板「会议记录员:打开」/「立即开始录音」,或工作台侧栏「会议记录员」Space。也可整目录压缩为单层 zip 经 Forsion 应用市场安装。

## 功能

- **会中**
  - 只采麦克风录音(覆盖线下会议与外放通话),`MediaRecorder` 按「转写分段时长」(默认 5 分钟,2-15 可调)分段轮转;每段经 Forsion 自己的语音链路(`window.tangu.transcribeAudio`,设置 → 语音)转写,时间戳自动加上段偏移并入总转写。
  - **每段转写完成即落盘**:崩溃/断电最多丢当前段;下次打开索引自愈,把残留的「录音中」状态降为「待纪要」。
  - 要点速记:Enter 落一条,自动带相对时间戳(如 `10:03` = 会议开始后 10 分 03 秒)。
  - 大计时器 + 实时波形(AnalyserNode)+ 分段进度(第 N 段 / 已转写 M 段);某段转写失败只留占位行,**不中断录音**。
  - 录音状态在模块级:关掉视图录音不断,状态栏显示「● 录音中 12:34」,点击回到视图。
- **会后**
  - 「生成纪要」:随包「会议书记官」Agent(未播种、或首轮产出不符合约定格式时,自动回退默认助手重试一次,行为一致)只根据要点与转写产出纪要 + 行动项,**绝不发明会上没说过的决议**;插件解析 ```minutes 代码块后**外科式**回写:纪要节整节替换;行动项节做**合并**——同文案行的勾选状态原样带过(勾过的不弹回),模型这轮没给的行动项行(你手写补的 / 上一轮产出)保留缀后;其它节(要点 / 转写 / 你自加的节)一字不动。
  - 纪要 / 转写 / 行动项三个标签页;导出 MD、复制、在笔记中打开。
- **行动项总览**
  - 聚合全部会议的未完成 `- [ ]` 项,按截止日排序、过期红标;勾选直接回写原文件该行(只翻复选框字符,该行其余内容一字不动)。
  - 行格式钉死:`- [ ] 内容 @负责人 📅YYYY-MM-DD`(负责人 / 日期可缺省)。

## 用法

1. 命令面板「**会议记录员:打开**」进入工作台;或「**会议记录员:立即开始录音**」以默认标题直接开录。
2. 填标题 / 与会人 → 「开始录音」(首次会请求麦克风权限)。
3. 会中:左栏实时转写,右栏 Enter 记要点。
4. 「结束录音」→ 完成剩余分段转写 → 「生成纪要」。
5. 「行动项总览」标签页跨会议追踪待办。

## 数据存哪

- 会议笔记:`<工作文件夹>/<YYYY-MM-DD>-<标题>.md`(工作文件夹默认「会议记录员」,插件详情页可改)。就是一篇普通 Markdown 笔记,可直接在 Amadeus 里打开、编辑、双链引用:

  ```markdown
  ---
  mt_title: 周会
  mt_date: 2026-08-06T10:00:00.000Z
  mt_status: recording      # recording | transcribed | done
  mt_attendees: 张三, 李四
  ---

  ## 要点速记
  - 10:03 预算砍 20%

  ## 转写
  [00:00:12] 大家好,今天……

  ## 纪要
  (会后 AI 生成)

  ## 行动项
  - [ ] 跟进供应商报价 @张三 📅2026-08-10
  ```

- 索引:`<工作文件夹>/.meeting-index.json`(隐藏 sidecar);打开时自愈——孤儿剔除、状态与待办数按文件实况重算。

## 范围说明(明确不做什么)

- **只采麦克风**:不做系统音频捕获(macOS 需虚拟声卡,明确不做)。线上会议请外放,或让声音进得了麦克风。
- **不保存音频原文件**:插件只有文本写入通道,每段音频转写完成即弃;转写文本就是产物。
- **转写零配置**:识别走用户在 设置 → 语音 里选的模型(本地离线 / 自带 key / Forsion 云),本插件不自带 ASR 供应商、不需要额外 key。
- **App 关闭 = 录音结束**:没有后台进程;开录前界面有提示。分段轮转在段边界有数毫秒采集间隙(MediaRecorder stop→续录固有代价),对会议转写无感。
- **录音进行中请勿同时在笔记编辑器里编辑这份会议文件**:录音机每段/每条要点会整文件重写草稿,双方写同一文件时后写覆盖先写。录音结束后随便编辑:「生成纪要 / 重新生成」只动纪要与行动项两节,且行动项是合并语义(勾选状态与手写行动项行保留);唯一不保证的是行动项节里的**非行动项自由文本**(该节请只放 `- [ ]` 行)。
- 纪要生成需登录 Forsion 并连接本机 Tangu 引擎;录音与转写不依赖引擎。
